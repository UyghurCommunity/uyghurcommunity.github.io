02 / ئۆز تۈرىڭىزگە

بىر بۇيرۇق بىلەن باشلاڭ.

نەشرى بەلگىلەنگەن GitHub ئارخىپلىرىدىن بىۋاسىتە قاچىلاڭ. ھەر بىر بوغچىنىڭ ئۆزىگە خاس قوللانمىسى ۋە مىساللىرى بار.

npm registry دا ئېلان قىلىش تېخى تاماملانمىدى؛ بۇ بۇيرۇق GitHub نەشر ئارخىپىنى ئىشلىتىدۇ.
